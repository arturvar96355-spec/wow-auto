# Правила контента Kovagor

Сайт-концепт делается до первого контакта с клиентом. Любой выдуманный факт — это потеря доверия на встрече. Эти правила важнее красоты.

## 1. Только проверенные факты

- Источник фактов — **только** часть А промпта (раздел «Проверенные факты»). Всё, чего там нет, — заглушка.
- Заглушка выглядит так: `[что нужно — откуда взять]`, например `[цена от … ₽ — от клиента]`, `[режим — уточнить]`.
- Заглушки в интерфейсе оформляются компонентом `<Placeholder>`: пунктирная рамка 1 px, приглушённый цвет, моноширинный шрифт 0.9em. Их должно быть видно, а не прятать.
- Никогда не придумывать:
  - цены, сроки, проценты, «N довольных клиентов», «98% успеха»;
  - годы основания, стаж, регалии, награды, номера лицензий;
  - отзывы, имена клиентов, должности сотрудников;
  - технические характеристики материалов и оборудования.
- Если в промпте цифра помечена «для понимания уровня» или «не публиковать» — она не появляется на сайте.

## 2. Отзывы

- Только цитаты из списка в промпте, дословно. Разрешено исправить явную опечатку (одну букву), смысл и стиль не трогать.
- Подпись: имя (как в промпте) + «Отзыв на Яндекс Картах». Фамилии и фото авторов не ставить.
- Рядом с блоком отзывов — ссылка на все отзывы на Картах с реальным числом.

## 3. Люди

- Сотрудники клиента — монограмма с инициалами на фирменном фоне и подпись `[фото — от клиента]`.
- Стоковые люди никогда не выдаются за сотрудников, врачей или мастеров клиента.

## 4. Обращение и язык

- К клиенту на «Вы»: **Вы, Вам, Вас, Ваш** — всегда с заглавной.
- Короткие предложения, конкретика вместо штампов. Запрещены: «индивидуальный подход», «команда профессионалов», «высочайшее качество», «лучшие цены», «№1».
- Без канцелярита («осуществляем», «предоставляем услуги по…»).

## 5. Типографика

Сделай `lib/typograph.ts` и прогоняй через него все строки из `/content`:

```ts
const NBSP = ' ';
export function typograph(s: string): string {
  return s
    // неразрывный пробел после коротких предлогов и союзов
    .replace(/(^|[\s(«])([а-яёА-ЯЁ]{1,2})\s/g, `$1$2${NBSP}`)
    // число + единица / ₽ / %
    .replace(/(\d)\s(₽|%|°|мин|ч|км|м|см|мм|лет|года|год|дн)/g, `$1${NBSP}$2`)
    // тысячи: 75000 -> 75 000
    .replace(/\b(\d{1,3})(?=(\d{3})+\b)/g, `$1${NBSP}`)
    // тире
    .replace(/\s-\s/g, `${NBSP}— `)
    // кавычки-ёлочки
    .replace(/"([^"]*)"/g, '«$1»');
}
```

## 6. Метка концепта и индексация

- В `<head>`: `<meta name="robots" content="noindex, nofollow">`.
- `public/robots.txt`: `User-agent: *` / `Disallow: /`.
- В футере мелко: «Концепт сайта, подготовлен для [название клиента] студией Kovagor. Не является официальным сайтом компании».

## 7. Чужие бренды

- Марки автомобилей, плёнок, препаратов и оборудования пишутся только текстом.
- Не ставить логотипы брендов и не писать «официальный дилер / партнёр», если это не подтверждено в промпте.

## 8. Медицина и юридические темы

- Медицинские услуги: без обещаний результата, обязательное предупреждение «Имеются противопоказания. Необходима консультация специалиста», номер лицензии — заглушкой.
- Законы и нормы (например, светопропускание тонировки): ссылаться на документ и не давать юридических советов. Числа из закона перед публикацией сверить веб-поиском.

## 9. Проверка перед сдачей

Скрипт `npm run placeholders` выводит все `[…]` из `/content` и компонентов. Его вывод вставляется в `README.md` как список «что запросить у клиента».

```js
// scripts/placeholders.mjs
import { readFileSync, readdirSync, statSync } from 'node:fs';
import { join } from 'node:path';
const out = new Set();
function walk(d) {
  for (const f of readdirSync(d)) {
    const p = join(d, f);
    if (statSync(p).isDirectory()) walk(p);
    else if (/\.(ts|tsx|md|mdx)$/.test(f))
      for (const m of readFileSync(p, 'utf8').matchAll(/\[([^\]\n]{3,120}?)\]/g))
        if (/[а-яё]/i.test(m[1])) out.add(m[1]);
  }
}
['content', 'components', 'app'].forEach((d) => { try { walk(d); } catch {} });
console.log([...out].sort().map((s) => `- [ ] ${s}`).join('\n'));
```
