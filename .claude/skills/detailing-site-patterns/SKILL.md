# Паттерны для детейлинга и тонировки

В детейлинге клиент выбирает глазами. Каждый интерактив должен **показывать** разницу, а не описывать её.

## 1. Примерка тонировки

**Структура данных** (`content/tint.ts`):

```ts
export type GlassZone = 'rear' | 'front-side' | 'windshield-strip' | 'all';
export const tintLevels = [5, 15, 20, 35, 50, 70, 80] as const; // % светопропускания
export const tintZones: { id: GlassZone; label: string; legalNote?: string; time: string | null; priceFrom: number | null }[] = [
  { id: 'rear', label: 'Задняя полусфера', time: 'около 40 минут', priceFrom: null },
  { id: 'front-side', label: 'Передние боковые', legalNote: 'front', time: null, priceFrom: null },
  { id: 'windshield-strip', label: 'Полоса на лобовое', legalNote: 'front', time: null, priceFrom: null },
  { id: 'all', label: 'По кругу', time: 'около часа', priceFrom: null },
];
```

**Визуализация:**
- Слои: фото вида из салона → слой стекла (`<div>` с `background: var(--color-tint)` и `opacity = 1 - level/100 * 0.95`) → блик (градиент 8% белого).
- Переход `opacity` 250 мс. Ползунок — нативный `<input type="range">` со своим стилем (доступность бесплатно).
- Цифра светопропускания — крупно, tabular-nums, меняется с коротким «перелистыванием».
- Для передних стёкол — подсказка о норме по техрегламенту. Число сверить веб-поиском, без юридических формулировок.
- Схема авто сверху (SVG): стекла — отдельные `<path>` с `data-zone`; выбранные заливаются цветом тонировки.

## 2. Сравнение плёнок «под лампой»

- 2–3 типа плёнки табами. Сцена: лампа (SVG-конус света с анимированным градиентом) → стекло → «салон» с относительной шкалой нагрева.
- **Не показывать градусы и проценты**, если их нет в промпте. Шкала — 5 делений без подписи цифр, подписи «теплее / прохладнее».
- Отзыв клиента с реальной цифрой ставится рядом как цитата, с подписью.
- Таблица свойств — с галочками и тире, без выдуманных значений; неизвестное — `[уточнить]`.

## 3. Калькулятор защитной плёнки по зонам

**Схема:** SVG машины в двух видах (сбоку и сверху), каждая зона — `<path data-zone="hood">` и т. п. Зоны: капот, передний бампер, фары, передние крылья, зеркала, стойки, пороги, задний бампер, крыша, весь кузов.

**Пресеты:** «Зоны риска» (капот частично, бампер, фары, зеркала, стойки), «Передок» (капот, бампер, фары, крылья), «Весь кузов».

**Данные** (`content/ppf.ts`): цена по классу авто × зона, по умолчанию `null`. Если хотя бы одна цена `null` — вместо суммы выводить «Цена — после осмотра» и заглушку.

**Анимация выбора:** заливка зоны «наплывает» — градиент с `stop-offset` анимируется 0→1 за 400 мс. Под схемой — чипы выбранных зон (можно снять кликом).

**Доступность:** зоны — это кнопки (`role="button"`, `tabIndex=0`, `aria-pressed`), дублируются списком чекбоксов под схемой для скринридеров.

## 4. Слайдер «до и после»

- Два изображения одинакового размера, верхнее обрезается `clip-path: inset(0 X% 0 0)`.
- Ручка: drag (pointer events), клавиатура ←/→ шаг 5%, Home/End, `role="slider"` с `aria-valuenow`.
- Подпись «До» и «После» в углах; при первом появлении ручка сама «показывает» себя: 50% → 35% → 50% за 1.2 с.

## 5. Блик по кузову

```css
.gloss { position: relative; overflow: hidden; }
.gloss::after {
  content: ''; position: absolute; inset: -20%;
  background: linear-gradient(115deg, transparent 40%, rgba(255,255,255,.22) 50%, transparent 60%);
  transform: translateX(-60%); pointer-events: none;
}
.gloss.is-active::after { animation: sweep 1.6s cubic-bezier(.22,1,.36,1) forwards; }
@keyframes sweep { to { transform: translateX(60%); } }
@media (prefers-reduced-motion: reduce) { .gloss::after { display: none; } }
```

На десктопе блик в hero может следовать за курсором (смещение ≤ 30 px, lerp 0.08).

## 6. Сцена «накатывание плёнки»

Pin-сцена: стекло (SVG прямоугольник со скруглением) → маска плёнки движется справа налево по scrub → за краем маски едет ракель (небольшой SVG), за ним остаются 2–3 «капли», которые исчезают. Справа — шаги процесса. На мобильном — без pin, каждая карточка шага играет короткую версию при появлении.

## 7. Фото и иконки

- Иконки — Lucide, толщина 1.5. Без мультяшных машинок.
- Стоковые фото — тёмные, с отражениями; одинаковая цветокоррекция (контраст +, холодные тени). Без логотипов автопроизводителей; если логотип в кадре — кадрировать или размыть.
- Все фото — с подписью `[фото работ — от клиента]` и источником в `content/credits.ts`.
