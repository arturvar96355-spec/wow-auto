# WoW auto — концепт сайта

Тонировка и защитные плёнки в Марьино. Статический сайт на Next.js 16 (`output: 'export'`).

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # статическая сборка в out/
npm run placeholders # список всех заглушек [ … ] — что запросить у клиента
```

Тексты, цены и контакты лежат в `content/`. Решения — в `DECISIONS.md`, план — в `docs/PLAN.md`.
Деплой: Cloudflare Pages (build `npm run build`, output `out`) или GitHub Pages (`NEXT_PUBLIC_BASE_PATH=/wow-auto`).

## Скрипты
- `npm run shots` — скриншоты Playwright: `node scripts/shots.mjs <url> <путь> <имя> <ширины>`.
- `node scripts/interact.mjs` — автотест интерактивов (примерка, лампа, калькулятор, слайдер, форма, меню).
- `node scripts/scene.mjs` — скриншоты pin-сцены «Как проходит».

## Структура
`app/` — страницы · `components/sections` — секции · `components/widgets` — интерактивы · `content/` — тексты, цены, отзывы · `lib/` — типограф, заявка · `docs/` — ТЗ, обзор клиента, отзывы, план · `.claude/skills/` — правила проекта.

## Деплой
Cloudflare Pages: подключить репозиторий, build command `npm run build`, output `out`. Резерв — GitHub Pages: `NEXT_PUBLIC_BASE_PATH=/wow-auto npm run build`, папку `out` публиковать через `actions/upload-pages-artifact`. Для OG-картинок задать `NEXT_PUBLIC_SITE_URL`.
После выкладки открыть сайт с мобильного интернета без VPN: загрузка, шрифты, виджеты, форма.
