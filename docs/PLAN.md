# План работ

Источники: `docs/prompt.md` (ТЗ), `docs/overview.md` (обзор клиента), `docs/reviews.md` (150 отзывов), `.claude/skills/*`.

## Этапы

0. **Основа.** Скиллы, Next + Tailwind + Motion + GSAP + Lenis, тема, шрифты, `typograph`, `placeholders`. ✅
1. **Дизайн-система** `/styleguide`: цвета, типографика, кнопки (капсулы, магнитные), карточки с бликом, поля, бейджи, заглушки, `Reveal`, `SplitText`, `CountUp`.
2. **Контент и данные** в `/content`: `site`, `tint`, `films`, `ppf`, `services`, `reviews` (9 цитат из А2), `faq/steps`, `credits`.
3. **Главная, секции 1–3:** шапка с бейджем «Открыто до 21:00» (МСК), hero с бликом, полоса преимуществ, мобильная нижняя панель.
4. **Виджеты:** примерка тонировки → «Лампа» → калькулятор защитной плёнки → слайдер «до и после» → форма записи (`lib/booking.ts`, wa.me или `tel:`).
5. **Секции 7–14:** направления, «Как проходит» (GSAP pin + scrub, 250%, на мобильном без pin), гарантия, отзывы, «Как заехать», запись, футер.
6. **Внутренние страницы** из одного шаблона: `/tonirovka`, `/zashchitnaya-plenka`, `/atermalnaya-plenka`, `/polirovka-i-keramika`, `/himchistka`, `/ceny`, `/kak-zaekhat`, `/privacy`.
7. **QA и релиз:** скриншоты 360–1920, Lighthouse, reduced motion, чек-лист Б10, README со списком заглушек, OG-картинка, деплой на Cloudflare Pages (резерв — GitHub Pages).

## Правила
- После каждого этапа — сборка, скриншоты 390 и 1440, коммит.
- Факты только из части А. Неизвестное — заглушка.
- Анимируем только `transform`/`opacity`; `prefers-reduced-motion` отключает scrub и параллакс.

## Нужно от клиента
Цены «от»; фото работ, бокса и въезда; марки плёнок и статус дилера; условия гарантии; адреса точек и режим; способы оплаты; номер мессенджера; логотип и юрлицо.
